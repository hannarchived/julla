# Hanna Sandoval — Portfolio

Personal portfolio, project dashboard and tracker. Plain HTML, CSS and JavaScript, no build step.

## Files
- `index.html` — page content
- `style.css` — styles (glass containers, menu banner, dashboard)
- `script.js` — typing headline, particle lily, cursor glow, dashboard
- `lily-data.js` — the lily image used by the particle effect
- `assets/photo.jpg` — profile photo

## Run locally
Open the folder in VS Code and use the **Live Server** extension (right-click `index.html` → *Open with Live Server*), or just open `index.html` in a browser.

## Edit the dashboard
The default cards are in `script.js` (search for `PRJ-2026-001`). Move a card between `todo`, `doing` and `done` to change its column. If you have already visited the page, change the storage key (`hs-kanban2`) to see the update.

## Deploy
Push to GitHub, then **Settings → Pages**, choose the `main` branch and the root folder.
